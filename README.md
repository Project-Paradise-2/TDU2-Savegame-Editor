# TDU2 Savegame Editor

A savegame editor for **Test Drive Unlimited 2**, designed to make editing and managing your game saves easier.

The tool provides a convenient way to modify savegame data without having to manually edit binary files or work with complicated file structures.

## Features

- Edit supported savegame data
- View and modify game progression
- Modify player-related values
- Easy-to-use interface
- Direct savegame file handling
- No manual hex editing required

*More features and supported editing options will be documented as development progresses.*

## Installation

1. Download the latest release.
2. Extract the archive to any folder.
3. Run `TDU2SavegameEditor.exe`.

No additional installation is required.

## Usage

1. Start the TDU2 Savegame Editor.
2. Load your Test Drive Unlimited 2 savegame.
3. Modify the values you want to change.
4. Save your changes.
5. Start Test Drive Unlimited 2 and load your modified savegame.

## Savegame Location

Your savegame files are located in the Test Drive Unlimited 2 user profile directory.

Make sure you select the correct savegame before making any changes.

## Important

**Always create a backup of your original savegame before editing it.**

Modifying savegame files incorrectly may result in corrupted or unusable save data.

Use this tool at your own risk.

## Compatibility

- Game: Test Drive Unlimited 2
- Platform: Windows
